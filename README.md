# Museum Quest: Tracing the Pop

A Dragon Quest-style pixel museum game about Philippine popular culture, 2000-2010.
MO-HUM080, Group 3: Kaye, Yza, Kirsten, William, Mendoza.

Open `index.html` in a browser, or play it on GitHub Pages.
Controls: arrow keys / WASD to move, Enter / Space / E to talk and read, Esc for the menu, M to mute.
